# Saffraan & Sahara Restaurant Website

## Overzicht

Dit is de officiële website voor **Saffraan & Sahara**, een authentiek Midden-Oosters restaurant gelegen in Den Haag. De website toont het menu, informatie over het restaurant, reserveringsmogelijkheden, locatiegegevens en vacature aanbiedingen.

De website is gebouwd met PHP en HTML, met CSS voor styling en JavaScript voor interactieve elementen. Het is ontworpen om responsief te zijn en toegankelijk voor alle gebruikers.

## Kenmerken

- **Homepagina**: Introductie van het restaurant met hero-afbeeldingen en sfeerbeelden.
- **Menu**: Overzicht van voorgerechten, hoofdgerechten en desserts met prijzen.
- **Reserveren**: Online reserveringsformulier voor tafels.
- **Locatie**: Informatie over de locatie in Den Haag, inclusief contactgegevens.
- **Vacatures**: Overzicht van beschikbare banen in het restaurant.
- **Toegankelijkheid**: Inclusief tekstgrootte aanpassingen en ARIA-labels voor screen readers.

## Technologieën

- **Backend**: PHP (voor server-side includes en dynamische content)
- **Frontend**: HTML5, CSS3, JavaScript
- **Fonts**: Google Fonts (Cinzel, Lato, Playfair Display)
- **Afbeeldingen**: Eigen foto's van gerechten en interieur

## Installatie en Gebruik

### Vereisten

- Een lokale webserver zoals MAMP, XAMPP of Apache met PHP-ondersteuning.
- Een webbrowser (bijv. Chrome, Firefox, Safari).

### Installatie

1. **Clone de repository**:
   ```bash
   git clone https://github.com/jouw-gebruikersnaam/saffraan-sahara-website.git
   cd saffraan-sahara-website
   ```

2. **Plaats de bestanden in je webserver directory**:
   - Voor MAMP: Kopieer de map naar `Applications/MAMP/htdocs/`.
   - Voor XAMPP: Kopieer naar `htdocs` in je XAMPP installatie.

3. **Start je webserver**:
   - Open MAMP/XAMPP en start Apache en MySQL (indien nodig).

4. **Open in browser**:
   - Ga naar `http://localhost/saffraan-sahara-website/` (pas aan naar je setup).
